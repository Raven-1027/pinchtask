# TUI 交互式界面

pinchtask 提供基于终端的交互式界面（TUI），使用键盘快捷键管理项目和任务，无需记忆命令行参数。

## 启动

TUI 是可选功能，需要启用 `tui` feature 编译：

```bash
# 使用默认数据目录 (~/.pinchtask)
pinchtask tui

# 指定数据目录
pinchtask tui -D /path/to/data
```

如果未预编译 `tui` feature，可以使用：

```bash
cargo run --features tui -- tui
```

如果当前目录或上级目录存在 `.pinchproject` 文件，TUI 启动时会自动选中对应项目。

## 界面布局

TUI 采用左右分栏布局：

- **左栏**：项目列表，显示所有项目
- **右栏**：根据操作切换不同视图
  - **任务列表**：显示当前选中项目下的任务
  - **任务详情**：显示任务的清单、笔记、资源等完整信息
  - **任务表单**：创建或编辑任务的表单
  - **帮助面板**：快捷键参考

底部状态栏会根据当前焦点位置显示可用操作的提示。

## 全局快捷键

| 按键 | 功能 |
|------|------|
| `q` | 退出 TUI（帮助面板中为关闭帮助） |
| `Ctrl+C` | 强制退出 TUI |
| `?` | 显示/关闭帮助面板 |

## 左栏 — 项目列表

| 按键 | 功能 |
|------|------|
| `↑` / `j` / `k` / `↓` | 上下移动选中项目 |
| `→` / `Enter` | 切换到右栏，加载选中项目的任务列表 |
| `n` | 新建项目（弹出项目表单） |
| `e` | 编辑选中项目（弹出项目表单） |
| `d` | 删除选中项目（弹出确认对话框） |
| `r` | 刷新项目列表 |
| `Home` | 跳转到第一个项目 |
| `End` | 跳转到最后一个项目 |

## 右栏 — 任务列表

| 按键 | 功能 |
|------|------|
| `↑` / `j` / `k` / `↓` | 上下移动选中任务 |
| `Enter` | 查看任务详情 |
| `n` | 新建任务（自动关联当前选中项目，弹出任务表单） |
| `d` | 删除选中任务（弹出确认对话框） |
| `←` / `Esc` | 切回左栏 |
| `r` / `Ctrl+R` | 刷新任务列表 |
| `/` | 进入搜索模式，实时过滤任务 |
| `Tab` | 切换排序方式（创建时间 → 优先级 → 更新时间 → 循环） |
| `Home` | 跳转到第一个任务 |
| `End` | 跳转到最后一个任务 |

### 搜索模式

按 `/` 进入搜索模式后：

| 按键 | 功能 |
|------|------|
| 任意字符 | 追加搜索关键词 |
| `Backspace` | 删除末尾字符 |
| `Esc` | 取消搜索，清除过滤 |
| `Enter` | 确认搜索，保持过滤 |

## 右栏 — 任务详情

| 按键 | 功能 |
|------|------|
| `↑` / `j` / `k` / `↓` | 上下移动清单条目焦点 |
| `Space` / `x` | 切换当前条目的完成/未完成状态 |
| `a` | 添加清单条目（弹出输入框） |
| `e` | 编辑当前条目名称（弹出输入框） |
| `E` | 编辑任务（切换到任务表单） |
| `d` | 删除当前清单条目 |
| `N` | 添加笔记（弹出输入框） |
| `D` | 删除笔记（弹出确认对话框） |
| `L` | 添加资源链接（两步输入：名称 → URL） |
| `Ctrl+D` | 删除当前任务（弹出确认对话框） |
| `Ctrl+J` | 将当前条目向下移动一位 |
| `Ctrl+K` | 将当前条目向上移动一位 |
| `←` / `Esc` | 返回任务列表 |

## 表单视图

任务表单和项目表单共享以下操作方式：

| 按键 | 功能 |
|------|------|
| `Tab` | 切换到下一个字段 |
| `Shift+Tab` | 切换到上一个字段 |
| `Enter` | 提交表单 |
| `Esc` | 取消并返回 |

### 任务表单字段

任务表单包含以下字段：描述、上下文、优先级、标签、预计完成时间。

**优先级字段**使用枚举选择模式，不支持直接输入：

| 按键 | 功能 |
|------|------|
| `Space` / `→` | 切换到下一个选项 |
| `←` | 切换到上一个选项 |

优先级选项循环顺序：空（不设置）→ `low` → `medium` → `high` → 空

### 项目表单字段

项目表单包含两个字段：名称、描述。

## 确认对话框

删除项目、删除任务、删除笔记时会弹出确认对话框：

| 按键 | 功能 |
|------|------|
| `y` / `Y` | 确认删除 |
| `n` / `N` / `Esc` | 取消删除 |

## 数据目录

TUI 与 CLI、MCP 服务器共享同一份数据存储。默认数据目录为 `~/.pinchtask/`，可通过以下方式自定义：

- 启动参数：`pinchtask tui -D /path/to/data`
- 环境变量：`PINCHTASK_DATA_DIR=/path/to/data pinchtask tui`
