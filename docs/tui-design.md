# pinchtask TUI 设计文档

## 1. 技术选型

| 组件 | 选择 | 理由 |
|------|------|------|
| TUI 框架 | ratatui 0.28+ | 活跃维护、社区最大、Widget 丰富 |
| 终端后端 | crossterm 0.28+ | 跨平台、异步友好 |
| 异步桥接 | tokio::sync::mpsc | 已在项目依赖中 |

## 2. 整体布局

```
┌──────────────────────────────────────────────────────┐
│  pinchtask TUI                          [筛选/排序]   │  ← 标题栏 (height=1)
├──────────────────────────────────────────────────────┤
│                                                      │

```

## 5. 状态机转换图

```
                    ┌─────────┐
         ┌────────>│  Help   │
         │ ?       └─────────┘
         │ Esc/?        │
         │              │
    ┌────┴────┐    ┌────┴────┐    ┌─────────┐
    │TaskList │───>│TaskDetail│───>│TaskForm │
    └────┬────┘    └────┬────┘    └────┬────┘
         │              │              │
         │  n           │  a/e (new)   │  Enter
         │──────────────│──────────────│
         │              │              │
         │  Enter       │  e (edit)    │  Esc
         │──────────────│──────────────│
         │              │              │
         │  Esc/←/h     │              │  Esc
         │<─────────────│              │
         │              │              │
         │  d (delete)  │              │
         │              │              │
         │  q / Ctrl+C  │  q / Ctrl+C  │
         └──────────────┴──────────────┘
                       │
                       ▼
                  (退出程序)
```

**转换规则：**
- `TaskList → TaskDetail`: 选中任务后按 `Enter`
- `TaskList → TaskForm`: 按 `n` 新建任务
- `TaskDetail → TaskForm`: 按 `a` 添加条目 / 按 `e` 编辑条目或任务
- `TaskDetail → TaskList`: 按 `Esc`/`←`/`h`
- `TaskForm → TaskList`: 提交成功后自动返回
- `TaskForm → TaskDetail`: 编辑条目提交后返回详情
- `TaskForm → 取消`: 按 `Esc` 返回上一视图
- `Help`: 从任何视图按 `?` 进入，按 `Esc` 或 `?` 返回
- 退出: 从任何视图按 `q` 或 `Ctrl+C`

## 6. 模块结构设计

```
src/tui/
├── mod.rs          # 模块入口，run() 函数，终端初始化/恢复
├── app.rs          # App 状态机：当前视图、选中索引、任务数据缓存
├── event.rs        # 事件定义与键盘事件流（crossterm → channel）
└── ui/
    ├── mod.rs      # UI 渲染入口，根据 App 状态分发到各视图
    ├── task_list.rs    # 任务列表视图渲染
    ├── task_detail.rs  # 任务详情视图渲染
    ├── task_form.rs    # 创建/编辑表单视图渲染
    ├── help.rs         # 帮助覆盖层渲染
    └── style.rs        # 统一颜色/样式定义
```

### 各文件职责

| 文件 | 职责 |
|------|------|
| `mod.rs` | 公开 `pub async fn run(store: TaskStore)` 入口；初始化终端（alternate screen + raw mode）；创建事件 channel；运行事件循环；退出时恢复终端 |
| `app.rs` | `struct App` 持有：当前视图模式（enum View）、任务列表缓存、选中索引、表单状态、消息/错误提示；`App::handle_event()` 方法处理按键分发 |
| `event.rs` | 定义 `enum AppEvent { Key(KeyEvent), AsyncAction(Action) }`；`EventStream` 从 crossterm 轮询键盘事件并通过 mpsc channel 发送 |
| `ui/mod.rs` | `pub fn render(f: &mut Frame, app: &App)` 根据当前视图模式调用对应渲染函数 |
| `ui/task_list.rs` | 渲染任务列表：表头、任务行（进度条、优先级标签）、选中高亮 |
| `ui/task_detail.rs` | 渲染任务详情：描述、元数据、清单列表、笔记、资源 |
| `ui/task_form.rs` | 渲染表单：输入框、下拉选择、清单条目编辑器 |
| `ui/help.rs` | 渲染半透明帮助覆盖层 |
| `ui/style.rs` | 集中定义 `ratatui::style::Color`、`Style`、`Modifier` 常量 |

## 7. 异步桥接方案

```
┌─────────────────────┐         ┌─────────────────────┐
│   TUI 事件循环       │         │   tokio 异步运行时    │
│   (同步, 60fps)     │         │                     │
│                     │         │                     │
│  crossterm 事件     │         │  core::initialize   │
│      │              │         │  core::mark_done    │
│      ▼              │         │  core::add_item     │
│  ┌────────┐  mpsc   │         │  core::remove_item  │
│  │ Event  │───────> │  spawn  │  ...                │
│  │ Stream │  tx     │ ──────> │                     │
│  └────────┘         │  async  │         result      │
│                     │  task   │            │        │
│  ┌────────┐  mpsc   │         │            ▼        │
│  │  App   │<─────── │ <────── │  Action { kind,     │
│  │ handle │  rx     │         │    payload }        │
│  └────────┘         │         │                     │
└─────────────────────┘         └─────────────────────┘
```

**流程：**
1. TUI 主线程运行 `crossterm` 事件轮询 + `ratatui` 渲染循环（~60fps tick）
2. 键盘事件通过 `mpsc::unbounded_channel` 发送到主循环
3. 当用户触发需要异步操作的动作（如创建任务、标记完成），主循环通过 `tokio::spawn` 提交异步任务
4. 异步任务完成后，将 `Action` 结果通过同一个 channel 发回主循环
5. 主循环在下一个 tick 处理 Action，更新 App 状态并重新渲染

**关键类型：**
```rust
enum AppEvent {
    Key(crossterm::event::KeyEvent),
    Tick,
    Action(ActionResult),
}

enum ActionResult {
    TasksLoaded(Vec<Task>),
    TaskCreated(Task),
    ItemToggled { task_id: String, index: usize, done: bool },
    ItemAdded { task_id: String, item: ChecklistItem },
    Error(String),
    // ...
}
```
